🌑 ## sHaDow remake
“借着月光行走，是一件很孤独的事。”

RE:sHaDow 是基于原版 Python 终端文字游戏《sHaDow》的 Unity 3D 完全重制版。
本项目不仅将原本的纯文本迷宫升级为了具有氛围感的 3D 场景，还引入了视觉小说（Visual Novel）级别的剧情演出和全新的镜头交互机制，为玩家带来沉浸式的心理悬疑探索体验。

✨ 重制版核心升级 (What's New in RE:sHaDow)
基于 Unity 引擎的强大表现力，重制版进行了以下脱胎换骨的进化：

🎬 AVG 剧情演出：新增了精美的角色立绘与对话系统（如角色 E.O），让碎片化的剧情故事更具代入感与情感共鸣。

🏙️ 3D 风格化场景：告别 ASCII 字符矩阵！现在你将在低多边形（Low Poly）风格的 3D 城市/迷宫网格中进行探索，幽蓝色的夜景光影完美还原了原版的压抑氛围。

🔄 动态视角转换 (Switch)：突破传统的单一俯视角！游戏右下角新增了“转换”机制，允许玩家在俯视角与平视/街道视角之间切换，用以观察地形或寻找隐藏线索。

UI 视觉重构：直观的图形化交互界面。屏幕左侧实时显示当前时段（如 深夜 23:00）、生存天数（day 0）与所在层级（layer 0）；右上方直观显示你当前最核心的筹码——理智值 (San: 100)。

⚙️ 继承的核心玩法
尽管画面迎来了次世代升级，但 RE:sHaDow 依然保留了最硬核的底层逻辑：

网格化回合制移动：在 3D 棋盘式地图上移动，或使用“等待 (WAIT)”指令跳过回合。

时间与理智管理：每一次行动都会推动时间流逝。在“深夜”的降临中，如何规划路线以维持 San 值，依然是你面临的最大考验。
